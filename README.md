## WARBANNERS ARE NOT BORING ANYMORE!

Customize your Warbanners any way **YOU** want!

Just drop your memes into  ***BepInEx/plugins/MemeBanner/Banners/***  and enjoy

This mod will **re-size** the files to fit on-to warbanner and **downscale** them so they wont ruin your fps!

You can use **.PNG / .JPG / .GIF** files! *(so basically any file!! wow!!!)*

Each banner gets its own random image, so **NEW LEVEL = NEW MEME**

## CONFIG

***Supports Risk Of Options***

* ### *UseStockAlphaMask (default: false)*
if **enabled**, images that don't have their own transperency will use the original game mask, preserving its original torn-cloth silhouette

Images that already have transparency will always keep it, regardless of this setting.

* ### *RandomBanner (default: false)*
if **enabled**, a random image will spawn each time - meaning that they can repeat.

if **disabled**, a que of images will generate - meaning no repetitions, and new image each time

* ### *CustomBannersFolder (default: empty)*
if **empty**, images are taken from the mod folder
